# MVT URL

**\[deprecated\]** Please url
[`tile_json()`](https://qfes.github.io/rdeck/reference/tile_json.md)
instead

## Usage

``` r
mvt_url(tileset_id)
```

## Arguments

- tileset_id:

  A mapbox tileset identifier of the form:

  - `mapbox.mapbox-streets-v8`, or

  - `mapbox://mapbox.mapbox-streets-v8`
