# Get event data

Get event data

## Usage

``` r
get_event_data(rdeck, event_name, session = shiny::getDefaultReactiveDomain())
```

## Arguments

- rdeck:

  \<`rdeck_proxy` \| `string`\> the map, or map id

- event_name:

  \<`string`\> the event name

- session:

  \<`ShinySession`\> the shiny session
